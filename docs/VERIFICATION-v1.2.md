# v1.2.0 — 戦闘・住宅・難易度改善パッチ検証

確認日：2026-11-03（日本時間）。v1.0 / v1.1の記録は既存の `VERIFICATION.md` / `VERIFICATION-v1.1.md` に履歴として保存。

## 実装した範囲

- 通常攻撃を10ダメージ・0.45秒CD・無料に変更。短い硬直、ノックバック、被弾無敵、HPバー、点滅、数値、軽量パーティクル、専用音、コミカルなK.O.を実装。
- 市民20 / 警官60 / 通常ドローン50 / 重装100HP。強化ドローン80HP。撃破後は同じランで復活せず、攻撃と残存弾を停止。
- 市民12%の回復、ドローン必須RAM、地面/家具への落下・浮遊・点滅・16秒期限・取得演出。報酬台帳と一意IDで重複取得を防止。ドローン取得はラン上限64GB。
- 敵の所属シーンを固定。市民は自宅、警官と通常ドローンは屋外、施設内の重装/強化ドローンは明示設定。視線遮蔽・捜索・帰還・射撃予告を追加。
- 手配度を0〜100の警戒値で再調整。同一視認で増え続けず、未発見5秒後に低下。増援は屋外のみ、固定ID・12秒間隔・警官追加2/ドローン2まで。
- 14棟、8住宅タイプ、8レイアウト系統、5/5/3/1の難度配分、1〜4PC、上段足場、家具障害物と遮蔽、6種の住民行動、無人の入門住宅。
- NORMAL 4:30 / CLASSIC 3:00の選択、時間割合で正規化したボーナス、モード別ベスト、戦績7項目。
- 既存の48×64主人公と28×58当たり判定、X/C/Q、RAM3値、PC回収、DataCenterRenderer、LABを継続使用。
