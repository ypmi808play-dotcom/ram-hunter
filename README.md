## 🌐 Web公開・オンラインプレイ（GitHub Pages / itch.io）

本作は**外部依存なし・単一HTML（スタンドアロンビルド）**で動作するため、GitHub Pages や itch.io 等を利用して**完全無料・サーバー設定不要**で誰でもブラウザから直接プレイできるように公開できます。

### 方法 1：GitHub Pages で公開する（推奨・自動ビルド）

本リポジトリには GitHub Actions 用ワークフロー（`.github/workflows/deploy.yml`）があらかじめ含まれています。

1. **GitHub で新しいリポジトリを作成**:
   - GitHub にログインし、`New repository` をクリック（Public 推奨）。
   - リポジトリ名を入力（例: `ram-hunter`）。
2. **コードをプッシュ**:
   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "feat: RAM HUNTER v1.4.0 Stealth & Combat Overhaul"
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. **GitHub Pages の設定を有効化**:
   - リポジトリの **Settings** > **Pages** を開く。
   - **Build and deployment** の **Source** で **「GitHub Actions」** を選択。
   - プッシュ時に Actions が自動実行され、数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` にてゲームが世界中に公開されます！

### 方法 2：docs フォルダから最速公開（ビルド不要）

本リポジトリの `docs/index.html` には最新ビルド済みゲーム本体が含まれています。

1. GitHub リポジトリの **Settings** > **Pages** を開く。
2. **Source** で **「Deploy from a branch」** を選択。
3. **Branch** を `main`、フォルダを **`/docs`** に設定して **Save** をクリック。
4. これだけで数秒後に公開完了となります。

### 方法 3：itch.io で公開する

1. [itch.io](https://itch.io/) にログインし、**Create new project** を選択。
2. **Kind of project** を **「HTML」** に設定。
3. `dist/RAM-HUNTER.html` を `index.html` にリネームしてZIP圧縮するか、`docs/index.html` をZIP化してアップロード。
4. **「This file will be played in the browser」** にチェックを入れ、画面解像度を `1280 x 720` に設定して公開。

## 🎯 主なゲームシステム

### 1. 視覚認識（視野角・距離）と段階的発見ゲージ（0〜100）
- **敵ごとの視覚プロファイル**:
  - 一般市民: 視野角110° / 視認距離210px / 発見速度 1.0x
  - 警戒住民: 視野角120° / 視認距離245px / 発見速度 1.25x
  - 民間警備員: 視野角125° / 視認距離270px / 発見速度 1.40x
  - エリート警備員: 視野角135° / 視認距離330px / 発見速度 1.70x
  - 警備ロボット: 視野角140° / 視認距離300px / 発見速度 1.45x
  - 戦闘ドローン: 視野角140° / 視認距離350px / 発見速度 1.55x
  - 監視カメラ: 視野角90° / 視認距離370px / 発見速度 1.85x（左右スイープ）
- **発見ゲージの挙動**:
  - `0`: 未認知
  - `1〜39`: 不審（頭上 `?` / 視認・音源方向を向く）
  - `40〜99`: 警戒確認（頭上 `?` / 接近して確認）
  - `100`: 発見確定（頭上 `!` / 発見SE / 追跡・攻撃移行）
- **正面・背後・遮蔽物・しゃがみ**:
  - 正面至近距離では約1秒以内に発見。背後からは視認されません。
  - しゃがみ移動中は敵の視認距離・発見速度が低減されますが、**遮蔽物のない正面至近距離（58px以内）では発見されます**。
  - ソファ・棚・パーティション等の遮蔽物に隠れると視線が遮られ、見失わせることができます。
- **RAM回収リスク**:
  - 回収作業中は周期的な作業音が発生し、視認時の発見速度が **1.35倍** に増加します。

### 2. 室内敵（Enemy A〜F）と特殊攻撃・予備動作
すべての特殊攻撃には **0.5〜0.7秒の明確な予備動作（警告テキスト＋発光リング＋SE）** があり、見てから回避・迎撃が可能です。

| 敵タイプ | HP | 特徴・特殊攻撃（予備動作） | ドロップ |
| :--- | :---: | :--- | :--- |
| **一般市民** (`resident` / `engineer`) | 20 | 接触攻撃（1ダメージ）、定期的な向き変更 | 12%でエナジードリンク（ライフ+1） |
| **警戒住民** (`alertResident`) | 40 | 高感度・発見時に **通報 (`⚠ CALLING HELP!`)** で同室内のNPCを警戒移行 | 12%でエナジードリンク（ライフ+1） |
| **民間警備員** (`privateGuard`) | 70 | 室内巡回＋定期的な振り返り・**警棒スイング突進 (`⚠ BATON SWING!`)** | なし |
| **エリート警備員** (`eliteGuard`) | 120 | **正面ガード（正面被ダメージ50%軽減・背面弱点）**＋**高速ダッシュ斬り (`⚠ DASH STRIKE!`)** | なし |
| **警備ロボット** (`securityRobot`) | 90 | 電撃弾射撃＋**EMPパルス (`⚠ EMP CHARGING!`)**（3秒間特殊能力 `X/C/Q` 封印） | **8〜32 GB RAM**（確定） |
| **室内戦闘ドローン** (`combatDrone`) | 65 | 空中浮遊・距離維持＋**3連バースト射撃 (`⚠ BURST FIRE!`)** | **16〜32 GB RAM**（確定） |

### 3. 14軒の5段階住宅難易度スケーリング
全14軒で遮蔽物・上段足場を活用したステルス攻略ルート（`hasStealthRoute`）が保証されています。

| 進行帯 | 住宅番号 | 難易度 | 室内セキュリティ | PC獲得RAM目安 |
| :--- | :---: | :---: | :--- | :---: |
| **序盤** | 住宅 1〜3 | `EASY` | 一般市民中心（1〜2体） | **4〜16 GB** |
| **中盤前半** | 住宅 4〜6 | `NORMAL` | 一般市民 ＋ 警戒住民 | **16〜64 GB** |
| **中盤後半** | 住宅 7〜10 | `HARD` | 警戒住民 ＋ 民間警備員 / 警備ロボット ＋ 監視カメラ(8〜) | **32〜128 GB** |
| **終盤** | 住宅 11〜13 | `VERY HARD` | エリート警備員 ＋ 警備ロボット / 戦闘ドローン ＋ 監視カメラ | **64〜256 GB** |
| **最深部** | 住宅 14 | `EXTREME` | AI Mega-Server Villa（エリート警備員＋ロボット＋ドローン＋監視カメラ2基） | **128〜512 GB** |

### 4. 住宅特殊イベントと途中撤退（RISK MODE）
- **住宅特殊イベント**:
  - `SLEEPING HOUSE`: 住民熟睡中（しゃがみで通過可能）
  - `ALARM PC`: 警報付きPC（室内のセキュリティ端末 `[E]` で解除可能）
  - `ATTIC ROUTE`: 天井ハッチから屋根裏の秘密通路へ
  - `RAM JACKPOT`: 1.5〜2倍容量の黄金発光PC
  - `EMPTY HOUSE`: 無人住宅（安全に回収可能）
- **途中撤退（EXTRACT RAM?）**:
  - 街の撤退バンで `E` 長押しすると、未消費RAMを100%安全に持ち帰ってリザルトへ移行可能。
- **RISK MODE**:
  - 有効時、ライフ0で未消費RAMの20%、時間切れで10%を喪失（途中撤退で確実な回収を目指すハイリスク・ハイリターン設定）。
